## [1.0.0] - 2026-09-08

### ✨ Added
- Initial official release of FontDeck Windows Desktop utility.
- Instant Windows system font library discovery via native Windows Registry integration.
- Custom folder watching with real-time filesystem change detection and parallel font parsing.
- Interactive typography canvas with custom pangram presets, size, line height, and letter-spacing controls.
- Font family grouping with detailed metadata inspection (PostScript name, format, copyright, weights).
- Custom font collections management with export and import functionality.
- Modern dark/light theme switching with smooth animations and responsive desktop layouts.
- Integrated automated updates with cryptographic signature verification.
- Offline-first privacy architecture with zero telemetry or network tracking.
